DEMO TITLE : Halloween 2021
DEMO NAME  : halloween_2021
FOLDER     : demo_halloween_2021
==============================================================================

ABOUT
-----
Halloween animation featuring Michael Jackson's "Thriller" with synchronized
MockingBoard music.

FILES REVIEWED
--------------
demo_halloween_2021.dsk (ProDOS volume /GREASY1.0): STARTUP/START2/START3/MESS
(Applesoft), THRILLER (frames), MJ.SPRITES, TT3.MCK (music), MOCK.INF, GREASE,
GRIDDLE, SLICK.

ATTRIBUTION
-----------
  * "Thriller" by Dan Henderson, 2021.
  * GReasy / Greasy Graphics lo-res sprite and animation library: Sellam
    Abraham.
  * MIDI-to-MockingBoard conversion with Midi2Mock (MIDITOMOCK): Tom Porter.

MUSIC
-----
  * "Thriller" by Michael Jackson (1982; written by Rod Temperton), converted
    from MIDI to MockingBoard data. This is a copyrighted song; the 8-Bit
    Shack license does not grant rights to it.
