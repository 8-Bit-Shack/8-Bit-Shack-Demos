==============================================================================
DEMO TITLE : Gothic Art
DEMO NAME  : gothic_art
FOLDER     : demo_gothic_art
==============================================================================

ABOUT
-----
Collection of atmospheric hi-res artwork (door, church, watermill, pub scenes)
with page-flipping animation.

FILES REVIEWED
--------------
demo_gothic_art.dsk (ProDOS volume /GOTHIC.ART): STARTUP, *.SCENE Applesoft
programs, hi-res pictures (DOOR1, COTTAGE, CHURCH, WATER.MILL, WAGGONHORSES,
...), small overlay sprites.

ATTRIBUTION
-----------
  * "Random Gothic Art" by Dan Henderson, 2020.
  * Scenes drawn in 816 Paint; originally intended for an adventure game.
