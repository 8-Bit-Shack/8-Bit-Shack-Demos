==============================================================================
DEMO TITLE : 3D Geometric Shape Demo
DEMO NAME  : 3d_render
FOLDER     : demo_3d_render
==============================================================================

ABOUT
-----
Real-time 3D geometric graphics (rotating wireframe objects, joystick/keyboard
control) demonstrating classic 6502 rendering techniques. Source for version
1.61 (May 2017).

FILES REVIEWED
--------------
PLOT3D.S (6502 assembly source), PLOT3D_REL.dsk (DOS 3.3 disk: PLOT3D8
program, OBJECT1-5.3D data, tables, Applesoft table-builders), README.md,
images/ (6 JPEG screenshots).
