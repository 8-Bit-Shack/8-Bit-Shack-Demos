==============================================================================
DEMO TITLE : XMAS 2020: Particle Simulation
DEMO NAME  : xmas_2020_particle
FOLDER     : demo_xmas_2020_particle
==============================================================================

ABOUT
-----
Self-running double-LORES Galton board simulation: 102 gravity-driven
particles, gravity reversal, user interaction, MockingBoard music. Apple //e,
128K, 1 MHz.

FILES REVIEWED
--------------
demo_xmas_2020_particle.dsk (DOS 3.3): HELLO, GALTON, SONG (PT3).

ATTRIBUTION
-----------
  * Uses the DOLORes double-LORES library.
  * "Merry X-mas 2020" message in the demo.
  * Published by 8-Bit Shack.

MUSIC
-----
  * PT3 tune "ideal weltall" by Key-Jee of Triebkraft, 3 November 2000
    (ProTracker 3.5 module).

THIRD-PARTY SOFTWARE / MATERIAL
-------------------------------
  * PT3-format music player.
