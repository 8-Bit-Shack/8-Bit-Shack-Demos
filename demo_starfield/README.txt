==============================================================================
DEMO TITLE : 3D Starfield Demo
DEMO NAME  : starfield
FOLDER     : demo_starfield
==============================================================================

ABOUT
-----
3D starfield with rotation, perspective and optional star trails. Keys: R
rotation, T star traces, C clear, Q quit. Detects MockingBoard and ZipChip.

FILES REVIEWED
--------------
starfield3D_2.dsk (DOS 3.3): HELLO, STARFIELD-3D (loader), STARFIELD, SHACK2
(splash). Also SF_noRot.mov, starfield_range.mov, starfield3D.png,
starfield3D.gif.
