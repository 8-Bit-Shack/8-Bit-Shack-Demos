==============================================================================
DEMO TITLE : Lens Demo
DEMO NAME  : lens_rc1
FOLDER     : demo_lens_rc1
==============================================================================

ABOUT
-----
Moving lens distortion effect (13x13 pixel lens over a background image) in
double LORES, with MockingBoard music. Apple //e (65C02), 1 MHz.

FILES REVIEWED
--------------
demo_lens_rc1.dsk (DOS 3.3): HELLO, LENS, FIREWORKS (Applesoft), SONG (PT3).

ATTRIBUTION
-----------
  * Uses the DOLORes double-LORES library.
  * "Merry X-mas 2020 and a happy new year!" and the tag "8-BIT-SHACK" appear
    in the demo.
  * Fireworks routine: FozzTexx, originally written in 1987 (third-party
    Applesoft code adapted in the demo).
  * Published by 8-Bit Shack.

MUSIC
-----
  * PT3 tune "Touhou Zero Track 1" by Gogin (Sergei Smirnov, ZX Evolution), 9
    June 2019 (ProTracker 3.5 module).

THIRD-PARTY SOFTWARE / MATERIAL
-------------------------------
  * FozzTexx: author of the original 1987 fireworks routine.
  * PT3-format music player.
