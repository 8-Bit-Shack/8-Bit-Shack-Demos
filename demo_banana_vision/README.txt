==============================================================================
DEMO TITLE : Banana Vision
DEMO NAME  : banana_vision
FOLDER     : demo_banana_vision
==============================================================================

ABOUT
-----
Dancing banana animation inspired by the classic Apple II AppleVision demo.

FILES REVIEWED
--------------
demo_banana_vision.dsk (ProDOS volume /CHRISTMAS): STARTUP, SPRITEMAKER,
SPRITEDRAW, VISION.SPRITES, IIEURO (hi-res picture), SND, PRODOS,
BASIC.SYSTEM.

ATTRIBUTION
-----------
  * Written by Daniel (Dan) Henderson as a homage to the original AppleVision
    from the DOS 3.3 system disk.
  * Sprite maker and sprite routines: Sellam Abraham.
  * Apple II picture drawn in 816 Paint; the banana uses shape tables.
  * AppleVision (the inspiration): Apple Computer.
