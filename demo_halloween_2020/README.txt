DEMO TITLE : Halloween 2020 Demo
DEMO NAME  : halloween_2020
FOLDER     : demo_halloween_2020
==============================================================================

ABOUT
-----
Collection of spooky pixel-art scenes accompanied by eerie music.

FILES REVIEWED
--------------
demo_halloween_2020.po (ProDOS volume /HALLOWEEN): STARTUP, HALLOW.FRAMES,
GRIDDLE, SLICK, SCRNADDRTBL, NOTE.PLAYER, TOCCATA.FUGUE.

ATTRIBUTION
-----------
  * "Halloween 2020" by Dan Henderson and Sellam Abraham ("Dan & Sellam").
  * GReasy / Greasy Graphics lo-res sprite and animation library: Sellam
    Abraham.

MUSIC
-----
  * Toccata and Fugue in D minor, BWV 565, by Johann Sebastian Bach (public-
    domain composition).
